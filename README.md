# 💥 نابودگر صفحه (Screen Destroyer)

**⬇️ دانلود:** [آخرین نسخه (APK اندروید، AppImage و deb لینوکس)](https://github.com/miladtavakoli/screen-destroyer/releases/latest)

یه اسباب‌بازی که روی صفحه می‌آد و می‌ذاره با دارت، چکش، مسلسل، بمب و شعله‌افکن «نابودش» کنی.
کد جلوه‌ها یک بار نوشته شده و روی اندروید و لینوکس عیناً همونه.

```
core/      موتور مشترک (HTML5 Canvas + Web Audio) — همه‌ی جلوه‌ها و صداها اینجاست
android/   پوسته‌ی اندروید (Kotlin): صفحه‌ی شفاف + کاشی Quick Settings برای اجرا روی هر برنامه
linux/     پوسته‌ی لینوکس (Electron): پنجره‌ی شفاف همیشه‌رو، روی همه‌ی مانیتورها
.github/   GitHub Actions: ساخت خودکار APK و AppImage/deb
```

## ابزارها
| | ابزار | کار |
|---|---|---|
| 🎯 | دارت | از پایین پرت می‌شه، تو صفحه گیر می‌کنه و می‌لرزه |
| 🔨 | چکش | شکستن شیشه با ترک‌های تار عنکبوتی و خرده‌شیشه |
| 🔫 | مسلسل | نگه دار و بکش: رگبار سوراخ گلوله |
| 💣 | بمب | فیتیل ۱ ثانیه‌ای، انفجار با آتش، دود، موج ضربه، لرزش و جای سوختگی |
| 🔥 | شعله | بکش تا رد دوده و آتش بمونه |

🧹 پاک کردن · 🔊 صدا · ⌄ جمع کردن نوار · ✕ خروج.
روی دسکتاپ: کلیدهای `1`–`5` برای ابزارها، `C` برای پاک کردن، `Esc` برای خروج. چندلمسی هم پشتیبانی می‌شه.

## اندروید
- **روی هر برنامه‌ای:** نوار اعلان رو بکش پایین و کاشی **«نابودگر 💥»** رو توی Quick Settings بزن. یه صفحه‌ی شفاف روی همون برنامه باز می‌شه.
  بار اولی که برنامه رو از آیکونش باز کنی، خودش پیشنهاد اضافه کردن کاشی رو می‌ده (اندروید ۱۳ به بالا). روی نسخه‌های قدیمی‌تر کاشی رو دستی از ویرایش Quick Settings اضافه کن.
- **از آیکون برنامه:** روی صفحه‌ی خانه باز می‌شه.
- Back یا ✕ مثل یه صفحه‌ی معمولی می‌بندتش.
- هیچ دسترسی حساسی لازم نیست (نه «نمایش روی برنامه‌های دیگر»، نه سرویس پس‌زمینه). فقط لرزش.
- حداقل اندروید ۸ (API 26).

ساخت دستی (با Android Studio یا SDK نصب‌شده):
```bash
cd android
./gradlew assembleRelease     # → app/build/outputs/apk/release/app-release.apk
```
### امضای APK
APKهای Release با کلید اختصاصی پروژه امضا می‌شن. کلید توی GitHub Secrets نگه‌داری می‌شه و توی ریپو نیست:

| Secret | مقدار |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | محتوای فایل `.jks` به base64 |
| `ANDROID_KEYSTORE_PASSWORD` | رمز keystore و کلید |
| `ANDROID_KEY_ALIAS` | `screendestroyer` |

اگه این Secretها تنظیم نشده باشن، APK با کلید debug ساخته می‌شه و **منتشر نمی‌شه**. از فایل کلید یه نسخه‌ی پشتیبان امن نگه دار؛ بدون اون، آپدیت‌های بعدی روی نسخه‌ی نصب‌شده نصب نمی‌شن.

## لینوکس
```bash
cd linux
npm install
npm start                 # پنجره‌ی شفاف (به یه compositor نیاز داره: GNOME, KDE, picom, …)
npm run start:screenshot  # اول از دسکتاپ اسکرین‌شات می‌گیره و روی اون کار می‌کنه (X11 بدون compositor)
npm run dist              # → dist/*.AppImage و dist/*.deb
```

## ساخت خودکار با GitHub
این پوشه رو push کن تو یه ریپو. Actions خودش APK و AppImage/deb رو می‌سازه (تب **Actions** ← آخرین اجرا ← Artifacts).
هر build موفق روی `main` یه Release با نسخه‌ی `linux/package.json` (مثلاً `v1.0.0`) می‌سازه یا به‌روز می‌کنه. برای نسخه‌ی جدید، `version` رو توی `linux/package.json` بالا ببر (و `versionCode`/`versionName` توی `android/app/build.gradle.kts`).

## اضافه کردن ابزار جدید
همه‌چیز توی `core/engine.js` هست: یه دکمه به `index.html` اضافه کن، یه تابع جلوه بنویس (روی `mctx` برای آسیب ماندگار، با `addParticle` برای ذرات)، و توی `pointerdown` صداش بزن. صداها توی `core/sound.js` با Web Audio ساخته می‌شن و فایل صوتی لازم ندارن.
